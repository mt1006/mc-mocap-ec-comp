Compatibility layer between [Motion Capture](https://github.com/mt1006/mc-mocap-mod) and [Emotecraft](https://github.com/KosmX/emotes) Minecraft mods.

It allows you to record Emotecraft emotes with Motion Capture mod and play them back.
